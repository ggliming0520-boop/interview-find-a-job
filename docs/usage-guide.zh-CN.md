# interview-find-a-job 使用指南

## 适合谁

适合正在准备面试的候选者。

## 最好提供什么

```text
JD / 岗位要求
你的简历
```

只提供一个也可以，但 AI 会提示限制。

## 推荐流程

1. 粘贴 JD 和简历。
2. 让 AI 生成岗位匹配和准备重点。
3. 开始模拟面试。
4. 一次回答一个问题。
5. 每题后查看回答建议。
6. 最后查看知识点和补课清单。

## 常用提示词

```text
面试准备
帮我做面试演练
请先问我自我介绍
根据我的回答帮我优化
总结我哪些知识点不牢靠
生成综合面试问题合集
```

## 输出特点

- 默认在聊天中输出。
- 默认不生成文件。
- 只有用户明确要求保存时，才生成文档。
