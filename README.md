# Interview Find a Job

面试-找到工作 / A Codex skill for candidate interview preparation, mock interviews, answer improvement, and review.

[中文 README](README.zh-CN.md)

## What it does

This skill helps candidates prepare for interviews using a job description, resume, and actual answers. It can run a one-question-at-a-time mock interview, improve answers, identify weak knowledge points based on answers, and summarize preparation priorities.

## Install

```bash
npx skills add ggliming0520-boop/interview-find-a-job
```

Manual install:

```bash
git clone https://github.com/ggliming0520-boop/interview-find-a-job.git "${CODEX_HOME:-$HOME/.codex}/skills/interview-find-a-job"
```

Restart Codex after installation.

## Quick start

```text
Use interview-find-a-job to help me prepare for this role.

JD:
<paste the job description>

Resume:
<paste my resume>
```
