# Interview Find a Job

面试-找到工作。

这个 skill 面向候选者，用来做岗位匹配、面试准备、模拟面试、回答优化和面试后复盘。

## 它能做什么

- 根据 JD 和简历生成面试准备重点。
- 按真实面试流程一题一题问。
- 根据你的回答给出更合适的回答建议。
- 根据你的实际回答指出不牢靠知识点。
- 总结需要补课的地方。
- 最后提示是否生成综合面试问题合集。

## 安装

```bash
npx skills add ggliming0520-boop/interview-find-a-job
```

手动安装：

```bash
git clone https://github.com/ggliming0520-boop/interview-find-a-job.git "%USERPROFILE%\.codex\skills\interview-find-a-job"
```

安装后重启 Codex。

## 快速开始

```text
用 interview-find-a-job 帮我准备面试。

JD：
<粘贴岗位描述>

简历：
<粘贴我的简历>
```
